# Studio Elegance — Landing Page Oficial 💈✨

> Landing page de alta conversão para o **Studio Elegance** (Estética Avançada & Barbearia de Alto Padrão).
> Inspirada no design editorial de luxo do template *Imageworks*, com tipografia refinada, layout responsivo e integração direta ao WhatsApp oficial.

---

## 📁 Estrutura do Projeto

```text
eleganciaestudio/
├── assets/                    # Identidade visual, logos, ícones e mídias
│   ├── instagram/             # Fotos reais de procedimentos e do espaço
│   ├── banner_luxury_marble.jpg
│   ├── logo.png
│   └── ...
├── data/                      # Dados estruturados e metadados
│   ├── instagram_data.json
│   └── instagram_detailed.json
├── docs/                      # Documentação e registros visuais
│   └── screenshots/           # Validações visuais desktop e mobile
├── .gitattributes             # Normalização de finais de linha Git
├── .gitignore                 # Arquivos ignorados pelo controle de versão
├── favicon.ico                # Ícone de favoritos oficial
├── index.html                 # Estrutura semântica principal
├── README.md                  # Documentação do projeto
├── script.js                  # Lógica interativa (filtros, agendamento, FAQ)
├── server.py                  # Servidor local Python Dual-Stack (IPv4/IPv6)
└── styles.css                 # Folha de estilos editorial e responsiva
```

---

## 🚀 Como Executar Localmente

### Pré-requisitos
* Python 3.8+ instalado.

### Inicialização Rápida
Abra o terminal na pasta raiz do projeto e execute:

```bash
python server.py
```

O servidor iniciará instantaneamente em:
👉 **[http://localhost:3000](http://localhost:3000)**

## 🎨 Características Técnicas & Design

* **Tipografia Editorial:** `Instrument Serif` para títulos elegantes e `Geist` para interface limpa e moderna.
* **Header Flutuante:** Cápsula minimalista fixa com navegação suave e acesso rápido ao agendamento.
* **Hero Interativo:** Fita 3D curva flutuante com fotos reais do espaço e trabalhos desenvolvidos.
* **Filtro de Procedimentos:** Categorização em tempo real (Sobrancelhas, Cílios, Barbearia, Facial).
* **Conversão Direta:** Todos os botões abrem diretamente o WhatsApp oficial com mensagem contextualizada para o procedimento selecionado.
* **100% Responsivo:** Otimizado para telas de smartphones, tablets e desktops de alta resolução.
